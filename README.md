# 불씨 대장간 — 모바일 게임 웹 시험판

[플레이](https://rubric-dev.github.io/ember-ore-play/) · 현재 버전과 소스 커밋은 build.json을 참고하세요.

휴대폰 터치와 PC 키보드로 실행하는 Godot 게임 테스트판입니다. 손님은 대장간으로 찾아오며, 일지에서 다시 초대할 수 있습니다. 광맥은 탐사 중 고갈되고 다음 탐사에서 복원됩니다. 목공 작업대에서 꾸미기 코너를 미리 보고 가구를 제작·배치할 수 있습니다.

M1 핵심 루프 재작업 중이며 최종 아트·전체 본편·Android/iPhone 설치판 검증 완료를 뜻하지 않습니다. 진행은 같은 브라우저에 저장되며 설치판과 자동 동기화되지 않습니다. 이전 저장 원본은 보존하고 새 형식으로 한 번 이관합니다. 여러 탭의 진행을 병합하지 않습니다.
